# Student Grade Calculator

## Description

This Java program displays student information and calculates the average of three assignment grades. It uses an `if/else` statement to determine whether the average is passing or failing. A passing average is 70 or higher.

## Requirements

- Java Development Kit (JDK)
- A terminal or Visual Studio Code

## How to Run

1. Open the `Module1` folder in VS Code.
2. Open the terminal in that folder.
3. Compile the program:

   ```powershell
   javac StudentGradeCalculator.java
   ```

4. Run the program:

   ```powershell
   java StudentGradeCalculator
   ```
